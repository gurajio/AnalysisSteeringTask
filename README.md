# Steering Lab

`inputCSV/`にあるCSVを読み込むローカル分析システムです。

## 起動

このフォルダで次を実行します。

```sh
.venv/bin/python app.py
```

ブラウザで http://127.0.0.1:8765 が開きます。終了はターミナルでCtrl+Cです。
別のポートを使う場合は`--port 8766`を指定してください。

初回セットアップをやり直す場合（Python 3.13で動作確認）：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

## 操作

- 参加者と条件のチェックボックスを操作すると自動更新します。
- 通常ページは平均値・推移・集計を表示します。ヘッダーの「回帰ページへ」から、同じ設定を持つ7モデル比較ページへ移動できます。
- practice/post、coreMtMs/mtMs、参加者別/等重み平均、10/50/100試行平均を切り替えられます。
- 「分析する試行範囲」で開始・終了を指定すると、その範囲だけで平均値・推移・MT回帰を再計算します。例：開始1、終了100。終了を空欄にすると最後まで。元の試行番号は保持します。
- 初期状態では`countedAsTrial=true`かつ`coreExitMs`が欠損していない試行のみ採用します。core通過後の`success=false`も採用します。基本除外を解除すると再試行・coreExitMs欠損行もERの分母に含まれます。
- MT外れ値は「除外なし」「同一試行番号の平均MT ±3SD」「習熟曲線からの残差 ±3SD」から選択できます。初期状態は除外なしです。判定は選択した試行範囲とMT区間に基づき、除外された行はMTだけでなく全指標から除かれます。
- 「100・200・300試行の周辺10試行を分析から除外」を有効にすると、96–105、196–205、296–305試行を全指標と回帰から除外します。元データは変更しません。
- `errorType=deviation`のみERに含めます。core選択時は逸脱イベントとの時間重なりで判定し、core外の逸脱は別表示します。
- PNGを保存する図のボタンを押すと、表示した画像そのものが`output/`に1600×1000pxで保存されます。
- 保存名には図の種類・phase・MT区間・条件・表示方法・集計幅・除外設定・参加者・日時を含めます。
- CSV追加・変更後は「inputCSVを再読み込み」を押してください。読み込みエラー時は旧データを維持し、エラーを表示します。
- 元データは変更しません。実験システムやPDFは実行時には必要ありません。

## 計算

詳細はAGENTS.mdと画面下部の「計算と表示のルール」を参照してください。
30度の直線通路を対象にしています。他の通路形状のデータにはそのまま使用できません。
MT・TPeは有効値のみを集計し、計算不能数を表示します。ERの区間判定が不能な行を含む集計は値を表示しません。
参加者平均は条件ごとに等重みで計算します。参加者数が異なる条件を混ぜません。
回帰ページはpracticeの試行番号ごとのMTを使い、表示の集計幅を変更しても回帰対象は変わりません。
同一試行番号の3SDはcondition・試行番号ごとの標本SD、習熟曲線の3SDは参加者・conditionごとの曲線残差の標本SDを使用します。有効値不足やSD=0では外れ値判定を行いません。
回帰ページでは、べき乗則、終端値付きべき乗則、指数関数、作業時間下限、習熟不能時間、過去経験、変化する習熟率の7モデルを縦に表示し、各図をPNG保存できます。1/TPe回帰は表示しません。
回帰は記述的な当てはめです。各モデルのパラメータ、R²、RMSE、点数を表示し、パラメータが境界に達した場合や識別が不安定な場合は警告します。
